# AI Usage Policy

AI-generated code is generally allowed in this project. Even entire features can be generated
completely by AI, as long as the code is good and reviewed.

## Terms

- **Review and understand generated code**

    Generated code MUST be reviewed, understood and, if necessary, manually modified before
    contributing it. It MUST be possible to maintain the code even without AI support.

- **Mark in pull requests**

    Commits don't need an assisted-by or similar marker, but in the pull request it is required
    to mark in the form and with a label that the PR contains generated code, together with a short
    note about what was generated in the PR.

## Restrictions

- **Agents are strictly forbidden from interacting with the repository.**

    This includes but is not limited to posting issues, making pull requests, posting comments,
    posting code reviews, adding reactions, etc. Any interaction on the repository must be done by
    a human. Pull requests created by AI agents will be rejected.

- **No walls of generated text in the documentation**

    Documentation is allowed to be generated, but AI can easily generate more text than anyone
    wants to read. It must be kept to a reasonable amount.

- **AI may not be used for issues marked as "good first issue".**

    These issues are intended for new contributors to learn the codebase, and are thus wasted if
    AI solves them.
